## 📘 图书简介

在数字繁荣与 AI 浪潮铺天盖地的今天，现代人陷入了一种隐蔽的集体焦虑：我们以为自己在掌控工具，实际上正在被工具无情地剥夺灵魂与能量。

本书从物理学（熵增与热力学第二定律）、控制论（Cybernetics）与人类演化认知的第一性原理出发，剥离流行语与商业包装，提出了 **`LGMT` 降熵模型（Lens 视角, Goal 目标, Method 路径, Tool 工具）**。

划定核心纪律：**顺序即纪律，位阶不可颠倒**。

---

## 🗂️ 目录与全书结构

全书采用“4 部 12 章（每部 3 章）”的完美对称结构，并引入 **阿杰（个人PKM）、老张（团队管理）、小雯（技术选型/AI）** 三位主角贯穿线：

* **《前言》** 写给每一个被工具压得喘不过气的人（含三车道阅读指南）
* **【第一部：立模篇 (破局与降熵骨架)】**
  * `01_第01章` 工具先行——现代人最隐蔽的认知陷阱
  * `02_第02章` 秩序的物理学——暴风雪中的求生骨架
  * `03_第03章` 四构件解构——Lens、Goal、Method、Tool 的极简说明书
* **【第二部：用模篇 (四大战场落地)】**
  * `04_第04章` 个人突破——彻底终结知识囤积与假装学习
  * `05_第05章` 团队对齐——告别大家都在忙却不知为了啥
  * `06_第06章` 系统与技术——避免千万级系统的填表灾难
* **【第三部：诊模篇 (逆向追查与防复发)】**
  * `07_第07章` 逆向追查——沿因果链拔除深层病根
  * `08_第08章` 反思与闭环——小错修路、大错换车、死路换地貌
  * `09_第09章` 防复发与自愈——打破防御性归因，建立自适应回路
* **【第四部：越模篇 (道法术器与边界)】**
  * `10_第10章` 古今归真——老祖宗的“道法术器”与控制论
  * `11_第11章` AI时代壁垒——把 Method 交给 AI，把 Lens 留给自己
  * `12_第12章` 终局心法——顺序即纪律，放下即成熟（含 Cynefin 适用边界）
