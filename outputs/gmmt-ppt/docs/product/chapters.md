## Page 4: 四层逻辑总览
- **Page Type**: Content
- **Page Title**: 四层逻辑总览（副标题：Goal → Lens → Method → Tool）
- **Selected Template**:
- **Content Structure**: (Concept)
  - 定义：GLMT 是一种排序纪律——解决"以什么顺序决定工具与方法"，而非"用什么工具"。
  - 四层卡片：
    - G · Goal 愿景目标：为什么做？做成什么样算成功？→ 提供方向与验收标准（本）
    - M · Lens 思维方式：这件事的第一性原理是什么？→ 提供解读问题的透镜（本）
    - M · Method 具体方法：具体怎么做？→ 把抽象认知变为可操作流程（末）
    - T · Tool 工具：用什么放大效率？→ 把流程变为可规模化执行（末）
  - 核心洞察（两种用法，全篇脊柱）：
    - 规划模式（自上而下）：从 G 推到 T，适用于"我已清楚要做什么"。
    - 诊断模式（自下而上）：从 T 的故障向上溯源，适用于"出问题了 / 还没想清"。
  - 关键句：展示顺序是规划者的递推，发现顺序是学习者的溯源；两种都用，别只认一种。
- **Content Density**: Medium
- **Narrative Role**: 建立四层与两种用法的核心框架
- **Image Requirements**: None
- **Page Weight**: Core page
- **Content Page Selection Rationale**: 全篇基石，后续所有章节都回指这四层与两种用法。

## Page 5: 四层如何互相支撑
- **Page Type**: Content
- **Page Title**: 四层如何互相支撑（副标题：优先级自上而下，能力自下而上）
- **Selected Template**:
- **Content Structure**: (Argument)
  - 核心论点：四层是一条单向支撑的因果链，方向有两重含义，并不矛盾。
  - 自上而下（决定优先级）：G 决定要不要做 → M 决定用什么眼睛看 → M 决定走哪条路 → T 决定踩什么油门。上层是下层的约束与存在理由。
  - 自下而上（能力支撑）：T 让 M 跑更快 → M 让 M 落地 → M 让 G 不被误读。下层是上层的实现手段。
  - 逐层机制：
    - Goal→Lens：目标越清晰，该掌握的"规律"搜索空间越小。
    - Lens→Method：心智模型是方法的"生成器"，方法质量上限由 Lens 保真度决定。
    - Method→Tool：方法不明确，工具就是没接线的零件。
    - Tool→（反哺）：好工具反哺方法与心智，但这是结果不是起点。
  - 类比收束：G=目的地，M=导航哲学，M=路线规划，T=你开的车。很多人先买跑车，才发现没决定去哪、也不认识路。
- **Content Density**: Medium
- **Narrative Role**: 解释层级依赖，破除"线性堆叠"误解
- **Image Requirements**: None
- **Page Weight**: Core page

## Page 6: 不可本末倒置
- **Page Type**: Content
- **Page Title**: 不可本末倒置（副标题：四类典型颠倒）
- **Selected Template**:
- **Content Structure**: (Problem/Solution)
  - 本与末：本=Goal+Lens（为什么/是什么，effectiveness）；末=Method+Tool（怎么做/用什么，efficiency）。颠倒=用效率替代效能、用手段替代目的。
  - 四类颠倒：
    - ① 工具先行：先买 Notion/上 AI/上 ERP，再想为什么。
    - ② 方法仪式化：照搬 OKR/敏捷/复盘会，却说不清为何适配。
    - ③ 思维模型收藏癖：囤"第一性原理""复利"当身份标签，从不回到 Goal。
    - ④ 目标置换（最隐蔽）：用代理指标代替真目标——Goodhart 定律（指标成目标就不再是好指标）。
  - 后果链：错误方向高效运行 → 沉没成本绑定 → 努力与结果脱节 → 工具成目的 → 环境一变即崩溃（无规律兜底）。
  - 深层代价：认知惰性——丧失从目标与规律独立思考的能力（恰是 Lens 该练的肌肉）。
- **Content Density**: Heavy
- **Narrative Role**: 全篇"反面教材"核心，后续案例反复印证
- **Image Requirements**: None
- **Page Weight**: Core page

## Page 18: 道法术器印证
- **Page Type**: Content
- **Page Title**: 道法术器印证（副标题：现代工程化精炼版）
- **Selected Template**:
- **Content Structure**: (Comparison)
  - 澄清：把"道法术器"连成四层框架并非某古籍原话，而是现代人从儒道兵提炼；精神源：老子道法自然、孙子道天地将法、王阳明知行合一。
  - 映射表（道法术器 | GLMT | 说明）：
