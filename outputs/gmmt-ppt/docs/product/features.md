# PPT Outline

## Overview
本课程将《GLMT 模型深度解读报告》转化为一套「五幕动词」结构的思维训练 PPT：懂它（模型本体）→ 用它（应用落地）→ 验它（对照与边界）→ 源它（文化根脉）→ 戒它（反思与行动）。全篇以"两种用法（规划模式自上而下 / 诊断模式自下而上）"为脊柱，帮助学员既掌握排序纪律，又知道何时该放下它。共 23 页，Chinese（中式水墨）风格，全程文字/卡片/表格排版。

## Design Style
Chinese（中式水墨）风格：宣纸米色背景、朱砂红/墨蓝主色、金色点缀；标题用 Noto Serif SC（衬线，传统典雅），正文用 Noto Sans SC（无衬线，清晰易读）。版式以卡片、分层堆叠、对比表格为主，强调留白与秩序感，呼应"排序"主题。
