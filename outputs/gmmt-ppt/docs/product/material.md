# Material: GLMT 模型（Goal-Lens-Method-Tool）深度解读课程

> 本课程的权威素材来自已定稿的《GLMT 模型深度解读报告》（/Users/hongyangchun/Codebase/default/outputs/GLMT模型深度解读报告.md），无需联网检索。以下为该报告的六维提炼。

## 1. Overview（概览）
- GLMT 不是"方法论集合"，而是一种**排序纪律（sequencing discipline）**：解决的是"以什么顺序决定工具与方法"，而非"用什么工具"。
- 四层：Goal（愿景目标）→ Lens（思维方式）→ Method（具体方法）→ Tool（工具）。核心理念：基于目标理解首要原则，培养正确思维，研究具体方法，挑选工具；**顺序不可本末倒置**。
- 全篇脊柱：**两种用法**——规划模式（自上而下，从 G 推到 T）与诊断模式（自下而上，从 T 的故障向上溯源）。展示顺序 ≠ 发现顺序。

## 2. Background（背景）
- 模型无单一创始人，是集成型实践框架：把东西方"目的优先 / 不可颠倒"的思想传统按目标→思维→方法→工具重新定序。
- 东方根：道法术器（老子、孙子、法家、儒家心学）；西方根：亚里士多德目的因、控制论、成长心态、系统动力学、科学方法、技术哲学。

## 3. Key Info（关键信息）
- 四层双向支撑：优先级自上而下（G 约束 M 约束 M 约束 T），能力支撑自下而上（T 放大 M，M 落地，M 保护 G）。
- 四类本末倒置：①工具先行 ②方法仪式化 ③思维模型收藏癖 ④目标置换（Goodhart 定律，最隐蔽）。
- 后果链：在错误方向高效运行 → 沉没成本绑定 → 努力与结果脱节 → 工具成目的 → 环境一变即崩溃（无底层规律兜底）。
- 业界约 70% 数字化转型失败，主因手段先行。

## 4. Evidence（证据/案例）
- 家庭收纳：刷小红书先买网红收纳盒（Tool 先行），跳过"乱的根因是东西多、位置漂移"（Lens 缺失）。（无配图）
- 企业销售提效：先上 OA/审批中台，为适配系统新增 N 个审批节点，销售填表时间翻倍——教科书式目标置换。（无配图）
- 个人成长：学英语先囤单词书/会员却不读不说；健身先买装备请私教却动作模式未建立就上重量，三个月受伤。（无配图）
- 个人知识管理：先花一周纠结 Obsidian/Notion 配主题，知识库空空；微信收藏以为存了=学了。（无配图）

## 5. Analysis（多视角对照）
- 与第一性原理：前者是 Lens 层修炼法，GLMT 给其"何时用、为谁用"的框架位置。
- 与手段-目的链：GLMT 正是对"手段-目的倒置"这一认知毛病的防御性纪律。
- 与黄金圈（Why-How-What）：黄金圈偏沟通对齐，GLMT 偏执行排序，可叠加。
- 与系统论：系统论从机制证明 GLMT 不能颠倒（目的性定速点/结构决定行为/杠杆点/局部优化）；GLMT 给系统论四层操作程序。
- 与 Cynefin：有序域（清晰/复合）严格自上而下成立；无序域（涌现/混乱）改用 Probe–Sense–Respond 涌现式。
- 与道法术器：GLMT 是现代工程化精炼版——把"道"拆为 Goal+Lens，显式单列 Tool，中性化"术"。

## 6. Outlook（局限与行动）
- 六大局限：目标涌现、分析瘫痪、琐碎任务过度工程、目标冲突、Lens 精英主义、文化适配。
- 七大谬误：锤子谬误、成就逻辑殖民生活、展示篡发现、层级傲慢、目标稳定幻觉、线性因果、测量塌缩。
- 适用光谱：绿（成就型任务，严格自上而下）/ 黄（目标需涌现，先用 Cynefin 判域）/ 红（关系/意义/审美，该放下框架本身）。
- 何时放下：本质是关系/意义/审美、为用框架而用、目标在涌现期、推演致拖延、多 Goal 打架。
- 落地清单（Cheat Sheet）：动手前四问（Goal/Lens/Method/Tool），四红线信号。
