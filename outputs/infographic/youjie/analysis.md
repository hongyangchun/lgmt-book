# Analysis: 有解 Skills 套件

## Source
基于《有解：高效解决问题的关键7步》的 KSME 问题解决 skill 套件（1 主入口 + 3 子模块）

## Topic
KSME 问题解决七步法的 AI Agent 技能包介绍

## Data Type
线性递进的七步流程

## Complexity
中等。七步法清晰但每步有深度，需要展现递进关系

## Tone
专业、引导式、给人信心。"你不需要一个人面对问题"

## Audience
面临问题需要系统解决方法的人、想提升解决问题能力的学习者、AI Agent 用户

## Design Instructions
- linear-progression 布局：七步法从左到右或从上到下递进
- hand-drawn-edu 手绘教育风格，亲切而不说教
- 中文文字
- 9:16 竖版用于微博发布
